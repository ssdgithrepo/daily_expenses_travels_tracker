SRD DriveLedger will ask your browser for location access to calculate the distance travelled, vehicle mileage and estimated fuel cost for this trip.

Enable location for this website
If you previously selected Block, the browser may not show the permission popup again. Use the browser's site permission/settings for this website, allow Location, then return here and tap Check Again.
  • Chrome / Edge: open the site → tap/click the lock or site-controls icon near the address bar → Site permissions / Permissions → Location → Allow → reload or Check Again.
  • Firefox: open the site → site information/lock icon → Permissions → Location → Allow → reload or Check Again.
  • Safari: use Safari website settings / Website Settings → Location → Allow, then return to this page.
  • Android/iPhone: if the browser itself has location disabled, enable Location permission for the browser in the phone's app/privacy settings first.
The website cannot silently change browser or device permissions. You remain in control.

How it works
  1. Choose your vehicle.
  2. Allow browser location permission.
  3. Start the trip.
  4. The app accumulates GPS distance using successive coordinates.
  5. Stop to save trip and calculate estimated fuel/cost.
Browser GPS accuracy varies. For production use, HTTPS is required by most browsers for location access.
