If you previously selected Block, the browser may not show the permission popup again. Use the browser's site permission/settings for this website, allow Location, then return here and tap Check Again.

How it works
  1. Choose your vehicle.
  2. Allow browser location permission once.
  3. Press Start Trip — the app accumulates GPS distance automatically.
  4. If you stop moving, tracking auto-pauses; it resumes by itself the moment you move again.
  5. You can log fuel top-ups mid-trip and the totals update instantly.
  6. Stop to save the trip with its distance and fuel cost breakdown.
Browser GPS accuracy varies from device to device.
Keeping the trip running in the background: this app requests a screen wake-lock and keeps listening for GPS updates while the tab is open, even if minimized briefly. However, phone browsers (especially Chrome/Safari on mobile) can pause JavaScript entirely once the screen locks or the browser is fully closed — that's an OS-level restriction no website can override. For uninterrupted long trips, keep the screen on and the tab open, or add this page to your home screen and keep it in the foreground.
