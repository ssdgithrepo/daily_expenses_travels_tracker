SRD DriveLedger will ask your browser for location access to calculate the distance travelled, vehicle mileage and estimated fuel cost for this trip.
Your browser will show the location prompt the moment you press “Start Trip” below — nothing is tracked before that.
To keep tracking running while you switch apps: keep this tab open (a screen wake-lock is requested automatically so the phone won't sleep) and, on Android, use "Add to Home screen" for the steadiest background behaviour. Whatever distance was recorded right up to that point is always saved automatically, so nothing is lost.

If you previously selected Block, the browser may not show the permission popup again. Use the browser's site permission/settings for this website, allow Location, then return here and tap Check Again.

How it works
  1. Choose your vehicle.
  2. Allow browser location permission once.
  3. Press Start Trip — the app accumulates GPS distance automatically.
  4. If you stop moving, tracking auto-pauses; it resumes by itself the moment you move again.
  5. You can log fuel top-ups mid-trip and the totals update instantly.
  6. Stop to save the trip with its distance and fuel cost breakdown.
Browser GPS accuracy varies from device to device.
Keeping the trip running in the background: this app requests a screen wake-lock and keeps listening for GPS updates while the tab is open, even if minimized briefly. However, phone browsers (especially Chrome/Safari on mobile) can pause JavaScript entirely once the screen locks or the browser is fully closed — that's an OS-level restriction no website can override. For uninterrupted long trips, keep the screen on and the tab open, or add this page to your home screen and keep it in the foreground.

Settings
If the map stays blank after saving a key, it's almost always one of these — all fixed in Google Cloud Console:
  1. Billing not enabled on the project (required even for the free monthly credit).
  2. Maps JavaScript API and Places API not enabled for the project.
  3. The key has an HTTP-referrer restriction that doesn't include this page's address — if you're testing by double-clicking the file (a file:// address) or from a new hosting domain, either remove the restriction while testing or add that exact address to the allowed list.
  4. A typo or extra space pasted into the key field.
Once you grant location access, tracking starts on its own as soon as you start moving — no need to tap Start. If you go quiet for 20 minutes, the trip/walk is automatically saved so nothing is ever lost, even if you forget to press Stop.
